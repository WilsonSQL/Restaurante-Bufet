# Modelo de datos y relaciones

La migración inicial define las tablas, claves primarias, claves foráneas y restricciones del sistema de restaurante.

Para documentar el modelo definitivo, generar un diagrama ER desde el esquema desplegado en Supabase (por ejemplo, Database → Schema Visualizer) y adjuntarlo aquí como `ModeloER.png` o exportación equivalente.

No asumir que el número de tablas o sus nombres sustituyen al diagrama: el equipo debe validar las relaciones directamente contra el esquema desplegado.
